# Kart Neon para Android

Este repositório guarda apenas os arquivos de instalação do aplicativo. O código do jogo não fica aqui.

## Como instalar

1. Abra a página de [versões](../../releases/latest) no celular.
2. Baixe o arquivo `.apk`.
3. Toque no arquivo e permita a instalação quando o Android pedir.

O Android mostra um aviso porque o aplicativo não vem da Play Store. Baixe somente por esta página.

Quando houver uma versão nova, o próprio aplicativo avisa e oferece o download. Basta instalar por cima, e o progresso é mantido.
